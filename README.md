## 🌸 Product Overview

**HER JOURNEY 240 — BODY, MIND & US ❤️** is a mobile-first, installable (PWA), privacy-focused holistic wellness companion designed for an adult woman beginning a sustainable fitness, nutrition, and self-care journey with the loving support of her partner.

It pairs an intelligent, personalized AI wellness companion (**Mira ❤️**) with respectful Indian home nutrition, kitchen food-scale awareness (distinguishing raw vs cooked metrics), beginner movement routines (including treadmill speed & incline presets), menstrual-cycle tracking, safe evidence-based resets, and voluntary partner connection without shame, guilt, or surveillance.

---

## 🌟 Core Modules & Features

### 1. Intelligent Built-in AI Companion (Mira ❤️)
- Accessible through a persistent floating button and header on every screen.
- Warm, empathetic, clinically safe persona.
- **Natural Language Understanding**: Answers questions about breakfast, biryani, pantry combinations, food-scale conversions, 10-minute workouts, period cramps, water weight, bloating, and more.
- **Structured Action System**: Mira doesn't just chat; she executes real actions in the app!
  - Previews proposed changes (e.g. meal replacement, water logging, workout duration adjustments, Minimum Viable Day activation).
  - High-risk / plan-altering actions display confirmation cards: `[Apply Changes]` or `[Keep Current Plan]`.
- **Speech-to-Text & Text-to-Speech**: Voice input via the Web Speech API with microphone toggle and audio speech synthesis.
- **Urgent Red-Flag Detection**: Automatically detects acute symptoms (chest pain/tightness, severe shortness of breath, fainting) and displays immediate urgent medical triage advice with verified emergency contact numbers.

### 2. Pre-Populated Starting Profile (Fully Editable)
- **Age**: 25 years
- **Height**: 157.5 cm (5 ft 2 in)
- **Weight**: 88.5 kg (Starting baseline; BMI screened neutrally as a reference point, never a measure of worth)
- **Goals**: Improve stamina, safely reduce body fat, build home cooking habits, feel energized and confident.
- **Experience**: Beginner (no gym membership or weights required).
- **Treadmill Availability**: Pre-configured with her tried settings: **Speed 5.0 km/h, Incline 2.0%, Duration 13 minutes**.
- **Food Preference**: Non-vegetarian Indian food (especially South Indian / Bengaluru home meals), with vegetarian alternatives.
- **Menstrual Start Date**: October 24, 2026 (Day 1 of 240!).

### 3. Cycle & Comfort Care (Menstrual Health)
- **Day 1 Focus (October 24, 2026)**:
  - *“You don’t have to push yourself today. Your body deserves care, patience and rest. Choose what feels comfortable — even resting is a valid choice. ❤️”*
  - Dedicated restorative routine: 3–5 min gentle stroll, shoulder rolls, seated side reaches, cat-cow spinal releases, and diaphragmatic belly breathing (adjustable down to zero).
- **Day 2 Protocol (October 25, 2026)**: 5–10 min easy walking, pelvic tilts, and optional 15 min stroll if feeling good.
- **Symptom Tracker**: Flow, cramps level (1–5), bloating, fatigue, tender back, and soothing hot water pack recommendations.
- **Strict Privacy**: Partner access to cycle data is **OFF by default**.

### 4. Food Planner & Kitchen Scale Confidence
- **Authentic Indian / South Indian Staples**: Sona Masoori rice, ragi flour / ragi roti, idli, dosa, vegetable upma, avalakki (poha), toor dal, Bengaluru sambar, beans & carrot palya, fresh curd, roasted chana, raw boneless chicken, home chicken curry, boiled eggs, egg bhurji, and fish curry.

  - Interactive Raw-to-Cooked Converter (e.g., 60g dry rice absorbs water to yield ~170g cooked rice; 150g raw chicken yields ~112g cooked meat).
- **Guilt-Free Meal Logging**:
  - *"I Ate Something Different"* modal allows logging any meal without moralizing, guilt, or "cheat meal" terminology.
- **Smart Leftovers & Low-Cost Pantry**: Easy recipe transformations (e.g., Sambar Avalakki, Shredded Chicken Wrap, Curd Rice).
- **Interactive Grocery List**: Categorized with checkable items.

### 5. Beginner Movement & Treadmill
- **Energy Level Switcher**: "Very low energy" (3–7 min), "Normal day" (12–15 min), "Feeling energized" (18–20 min).
- **Treadmill Session**: Speed 5.0, Incline 2%, 13 minutes with countdown timer, pause/play, and audio cues.
- **Chair-Supported Alternatives**: Every exercise has a zero-impact, chair-supported version.
- **Talk-Test (RPE 1–10)**: Prioritizes comfortable conversation over calorie burn or heart rate exhaustion.

### 6. Safe "Detox & Reset"

  4. *Daily 3 Healthy Habits*: Morning hydration, 10-minute stroll, and vegetable palya on the plate.

### 7. Mind, Mood & Emotional Wellbeing

### 8. Us / Relationship & Love ❤️

## 🛠️ Tech Stack & Architecture

- **Frontend**: React 18, TypeScript, Vite 6, Tailwind CSS
- **Design Tokens**: Warm cream (`#FAF7F2`), deep plum (`#2D1F3D`), dusty rose (`#E07A8A`), gentle coral (`#F08080`), lavender (`#9B87F5`), and sage green (`#52B788`)
- **Database**: Local-First IndexedDB via **Dexie.js** (Zero cloud data leakage; works 100% offline)
- **Backend API**: Express on Node.js (`server/index.js`) providing `/api/ai/chat` and `/api/health`
- **AI Integration**: Configurable Gemini / OpenAI adapter with a built-in offline intelligent wellness engine that generates typed structured actions
- **PWA**: `manifest.json`, Service Worker caching (`sw.js`), and mobile-responsive viewport

## 🚀 Getting Started

### 1. Prerequisites
- **Node.js** v18+ or v20+
- **npm** v9+

### 2. Installation
```bash
# Clone or open the project folder
cd Fitness_Plan

# Install dependencies
npm install
```

### 3. Environment Configuration (Optional)
Copy `.env.example` to `.env`:
```bash
cp .env.example .env
```
*(Optional) If you have a Google Gemini API key or OpenAI API key, insert it into `.env`. If left empty, the application runs its built-in Intelligent Wellness Engine seamlessly without crashing!*

### 4. Running the Application Locally
In two separate terminals:

**Terminal 1 — Backend AI API Server:**
```bash
npm run server
# Starts server on http://localhost:3001
```

**Terminal 2 — Frontend Vite Dev Server:**
```bash
npm run dev
# Starts app on http://localhost:5173
```

Open your browser and navigate to: **`http://localhost:5173`**

### 5. Building for Production
```bash
npm run build
```
This runs the TypeScript compiler and produces the optimized production bundle in the `dist/` directory.

---

## 📱 PWA Mobile Installation

1. Open `http://localhost:5173` on Google Chrome or Safari on your phone.
2. Tap the browser menu (`⋮` or Share icon).
3. Tap **"Add to Home Screen"** or **"Install App"**.
4. The app installs as a standalone, fullscreen mobile application with the custom lotus heart icon.

## 🛡️ Privacy & Medical Ethics Compliance

- **No Medical Diagnoses**: The app clearly identifies itself as an educational wellness companion.
- **Red Flag Symptom Interception**: Immediate medical assessment guidance is given for chest pain, fainting, or acute breathlessness.
- **No Crash Diets or Laxatives**: Rejects extreme caloric restriction, fasts, or unverified supplements.
- **Strict Partner Privacy**: Partner participation is voluntary; private health metrics require explicit consent.
- **Data Portability**: Full JSON / CSV exports and permanent one-click data erasure.
